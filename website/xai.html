Understanding what the models see

Accuracy alone does not tell the full story. Grad-CAM and SHAP reveal which parts of a face each model focuses on — and whether those regions are meaningful for emotion recognition.

Grad-CAM

Gradient-weighted class activation mapping

Grad-CAM visualises the regions of an input image that most influenced a model's prediction. Warmer colours (red, orange) indicate high importance; cooler colours (blue) indicate low importance. For facial expression recognition, we expect well-trained models to focus on emotionally expressive regions such as the eyes, eyebrows, and mouth.

SHAP

Shapley additive explanations

SHAP assigns each pixel a contribution score to the model's output — positive values push the prediction toward a class, negative values push away from it. Unlike Grad-CAM, SHAP provides a theoretically grounded attribution based on cooperative game theory.

[ SHAP pixel attribution map — placeholder ]

What SHAP shows

Red pixels contributed positively to the predicted class. Blue pixels contributed negatively. The Custom CNN shows concentrated positive attribution around the mouth curve and eye corners — consistent with the Grad-CAM findings.

Why it matters

When both Grad-CAM and SHAP agree on the same facial regions, we have stronger evidence that the model is learning genuine emotion-relevant features rather than spurious correlations in the training data.

What the explainability analysis tells us

  • Custom CNN focuses on emotionally relevant facial regions, validating its accuracy as meaningful.
  • Transfer learning models show diffuse attention — consistent with the domain gap hypothesis.
  • Agreement between Grad-CAM and SHAP across test images strengthens the interpretability findings.
