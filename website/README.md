# FaceXplain — Facial Expression Recognition

A one-page academic website for a Pattern Recognition M.Sc. final project at the University of Europe for Applied Sciences, Potsdam, Germany.

**Student:** Yada Thadathanacharoen  
**Program:** M.Sc. Software Engineering  
**Course:** Pattern Recognition — Phase 3 Final Project  
**Year:** 2026

## Project summary
Comparative analysis of three deep learning architectures (Custom CNN, MobileNetV2, ResNet50) on the FER-2013 facial expression dataset, with Grad-CAM and SHAP explainability.

## Best result
Custom CNN — 57.80% accuracy, F1 0.5165

## Pages
- Home — project overview and stats
- Models — architecture comparison and results table  
- Demo — interactive Streamlit demo link
- XAI — Grad-CAM and SHAP explainability analysis
